# Esp32s3-Keyboard

Прошивка, которая превращает плату ESP32-S3 с сенсорным экраном в беспроводную клавиатуру и тачпад для телевизора, компьютера или телефона.

- Клавиатура EN/RU с набором свайпом сразу на двух языках
- Тачпад: курсор, клики, прокрутка, перетаскивание
- Подключение по USB и по Bluetooth LE (до трёх устройств одновременно), выбор, куда печатать
- Цифры и символы программиста, F1–F12, навигация, мультимедиа
- Подсказки, автоисправление, обучение под руку пользователя

## Железо

| | |
|---|---|
| Плата | **Guition JC4827W543C** (ESP32-S3 N4R8: 4 МБ flash, 8 МБ PSRAM) |
| Экран | 4,3", 480×272, NV3041A (QSPI) |
| Тач | ёмкостный GT911 |

Подойдёт любая сборка JC4827W543 с ёмкостным тачем (буква **C** в конце). Плата с резистивным тачем (буква R) не поддерживается. Для других плат поправьте пины в `src/board.h`.

## Установка

### 1. PlatformIO

Нужен [PlatformIO](https://platformio.org/). Его можно поставить как расширение VS Code («PlatformIO IDE») или из командной строки:

```bash
python3 -m pip install --user platformio
```

Python нужен версии 3.10–3.14. Если системный Python новее, PlatformIO не запустится. Тогда используйте `pio` из его окружения: `~/.platformio/penv/bin/pio`.

### 2. Исходники

```bash
git clone https://github.com/SergeyKarleev/Esp32s3-Keyboard.git
cd Esp32s3-Keyboard
pio run
```

Первая сборка сама скачает платформу ESP32, Arduino и библиотеки (LVGL, Arduino_GFX, NimBLE). Это займёт несколько минут.

### 3. Первая прошивка

На чистой плате USB работает в режиме загрузчика. Поэтому в первый раз:

1. Подключите плату USB-кабелем к компьютеру.
2. Зажмите **BOOT**, нажмите и отпустите **RST**, отпустите **BOOT**.
3. Прошейте:
   ```bash
   pio run -t upload
   ```
   Если портов несколько, укажите порт явно:
   - macOS: `--upload-port /dev/cu.usbmodem1101`
   - Linux: `--upload-port /dev/ttyACM0`
   - Windows: `--upload-port COM5`
4. Нажмите **RST**: на экране появится клавиатура.

### 4. Следующие прошивки (без кнопок, macOS)

Прошивка поднимает на USB виртуальный COM-порт. Скрипт перезагружает плату в загрузчик через этот порт, прошивает и запускает её:

```bash
./tools/flash.sh
```

Скрипту нужен `esptool` в PATH (`pip install esptool`). На Linux и Windows используйте кнопки, как в шаге 3.

## Подключение

### По USB

Подключите плату к ТВ или компьютеру. Она определится как клавиатура и мышь «ESP32 Keyboard».

- **macOS** спросит, разрешить ли подключение аксессуара: нажмите «Разрешить». Окно «Ассистент настройки клавиатуры» можно просто закрыть.
- **Android TV / Android** подключают клавиатуру без настройки.

### По Bluetooth

1. На ТВ или компьютере откройте поиск Bluetooth-устройств.
2. Выберите **ESP32 Keyboard**. Код не нужен.
3. Значок Bluetooth в верхней панели загорится зелёным. Если он мигает, плата ждёт подключения.

Тап по значку Bluetooth включает и выключает Bluetooth. Если клавиатура перестала печатать после обновления прошивки, удалите её из Bluetooth-устройств хоста, в настройках платы нажмите «Забыть устройства» и подключите заново.

### Куда печатать

Плата может быть подключена сразу к нескольким устройствам. В ⚙ → «Куда печатать» выберите **Везде** или конкретное устройство из списка: компьютер по USB или Bluetooth-хост по имени.

## Раскладка и язык на устройстве-получателе

Клавиатура отправляет **коды клавиш**, а не буквы: какая буква напечатается, решает раскладка на ТВ или компьютере. Поэтому на получателе должны быть включены английская и русская раскладки, а плата должна уметь переключать их комбинацией клавиш.

| Получатель | Что настроить | Комбинация в ⚙ «Смена языка» |
|---|---|---|
| Android TV / Android | Настройки → Язык и ввод → Физическая клавиатура → ESP32 Keyboard → добавить «Русский» и «Английский» | Ctrl+Space |
| macOS | Системные настройки → Клавиатура → Сочетания клавиш → Источники ввода → включить «Выбрать предыдущий источник ввода» (Ctrl+Space) | Ctrl+Space |
| Windows | раскладки EN и RU в «Язык и регион» | Alt+Shift (или Win+Space) |
| Linux | зависит от окружения | та, что настроена в системе |

Кнопка **EN/RU** на клавиатуре меняет язык платы и отправляет получателю выбранную комбинацию. Если подписи на плате и раскладка получателя разошлись, **долгое нажатие на EN/RU** меняет только подписи, ничего не отправляя.

**Система получателя** (⚙): «Определять самой» по умолчанию. Mac плата узнаёт сама: по USB — по тому, как он запрашивает описание устройства, по Bluetooth — по производителю «Apple». Для Mac копирование и вставка идут через Cmd, а знаки печатаются по русской раскладке macOS. Если система определилась неправильно, выберите её вручную.

## Как пользоваться

### Клавиатура

- **Свайп**: проведите пальцем по буквам слова, не отрывая его. Слово и пробел напечатаются сами.
- Свайп понимает английский и русский сразу. Слово другого языка печатается без смены экранной раскладки: получатель переключается только на время слова.
- **Задержка на букве** (~¼ с) делает эту букву обязательной. Если задержаться на каждой букве, напечатается ровно это слово, даже если его нет в словаре.
- Сверху подсказки. Первое подсвеченное слово — то, что уже напечатано, тап по другому заменяет его.
- **Набор по буквам**: подсказки дополняют начатое слово. Автоисправление при пробеле исправляет опечатку на одну букву; исходное слово остаётся в подсказке, чтобы вернуть его.
- **?123**: цифры справа, символы слева. **Fn**: F1–F12, Esc, Tab, Home/End, PgUp/PgDn, Ctrl/Alt/Win, громкость.
- **Shift**: одно нажатие — следующая буква заглавная, двойное — Caps.
- **Верхняя панель**: выделить всё, вырезать, копировать, вставить, отменить.

### Тачпад

- Один палец двигает курсор, тап — клик.
- Ведёте курсор и тапаете вторым пальцем — левый клик. Держите второй палец — перетаскивание.
- Два пальца — прокрутка, тап двумя пальцами — правый клик.
- Двойной тап и ведение — перетаскивание.
- Полоса справа — прокрутка, кнопки **ЛКМ** и **ПКМ** снизу можно держать.

### Подстройка свайпа

- ⚙ → «Свайп под тебя» → **Тренировка**: проведите 12 показанных слов. Плата запомнит, насколько ваш палец смещается относительно клавиш и насколько неровно ведёт.
- Плата учится и сама. Выбранные подсказки и слова, исправленные после свайпа, запоминаются и поднимаются выше.
- **Сброс** забывает выученные слова и калибровку.

## Словари

Словари собраны из частотных списков [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles 2018, лицензия CC BY-SA 4.0): 50 тыс. английских и 75 тыс. русских слов. IT-лексика и сленг из `tools/words_en.txt` и `tools/words_ru.txt` поднимаются в начало списка.

Чтобы добавить слова:

1. Допишите их в `tools/words_*.txt`. Формат описан в начале файла. Для русских слов есть пометки склонения: `коммит:m` даст «коммита», «коммиты», «коммитов» и т. д.
2. Скачайте `en_full.txt` и `ru_full.txt` из FrequencyWords (`content/2018/en/`, `content/2018/ru/`) в отдельную папку.
3. Пересоберите словари и прошейте:
   ```bash
   python3 tools/gen_dict.py <папка со списками>
   ```

## Отладка

Плата пишет лог в USB-порт на скорости 115200 (`pio device monitor`) и принимает команды:

| Команда | Что делает |
|---|---|
| `S` | снимок экрана (`uv run tools/screenshot.py <порт> out.png`) |
| `T x y` | виртуальный тап (`uv run tools/tap.py <порт> x y`) |
| `D x y`, `M x y`, `U` | палец вниз, движение, вверх |
| `I` | состояние тача |
| `O` | USB-запросы хоста (определение Mac) |

## Устройство кода

| Файл | Что внутри |
|---|---|
| `src/main.cpp` | запуск, главный цикл, команды отладки |
| `src/hid.*` | USB HID (TinyUSB) и BLE HID (NimBLE), список устройств, определение Mac |
| `src/keyboard.*` | экранная клавиатура, слои, свайп, подсказки, автоисправление |
| `src/swipe.*` | распознавание свайпа (по мотивам SHARK2 / FlorisBoard), словари, обучение |
| `src/trackpad.*` | жесты тачпада |
| `src/ui.*` | верхняя панель и настройки |
| `src/touch.*`, `src/display.*` | драйверы тача GT911 и экрана NV3041A, LVGL |
| `src/settings.*` | настройки во flash (NVS) |
